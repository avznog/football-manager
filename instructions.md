App foot
- tout le git versioning doit être fait. L’entièreté des data de Claude doivent être sur git de sorte que je puisse reprendre facilement le travail sur plusieurs sessions Claude qui n’ont pas la même mémoire.  
- Il faut un login en user password. Trois types de comptes : super admin (peut tout faire), coach (membre d’une équipe) qui peut être aussi joueur (le coach doit pouvoir faire la même chose que les joueurs, et joueur. 
- Lorsqu’on arrive dans l’application, il faut rejoindre une équipe, sinon on a accès à rien. Le super admin nomme les coachs, et les coach’s peuvent nommer des coachs. 
- Chaque équipe a un ou plusieurs schéma de jeu différent (c’est du foot à 7 uniquement) : les joueurs peuvent, sur leur profil, indiquer à quels postes ils souhaitent jouer, sur un schéma de terrain en cliquant sur les postes qu’ils désirent. 
- Les comptes coach peuvent définir les compositions pour un match, sélectionner les joueurs qui seront sur la feuille de match. Ils peuvent indiquer qui jouera ou, indiquer, au préalable des changements pour X mn (en fait, le coach indique une nouvelle composition à X mn, les changements sont déduis). Le coach peut créer autant de compos à autant de moments qu’il veut pour le match. 
- Lorsqu’un match est joué, le coach peut y indiquer le résultat (qui est en fait déduit des actions indiquées pendant le match (mode jeu)). Les joueurs peuvent après mettre une note à tous les autres joueurs (eux aussi), avec un commentaire si besoin. 
- Calendrier des matchs
- Mode jeu : le mode jeu est le mode à activer lorsque le match commence. Lorsque l’on démarre sur le mode jeu, on voit à l’écran la composition actuelle, avec les joueurs du banc aussi. Il faut que le chrono soit affiché en haut. Il faut un bouton « action » style Waze, ou le coach peut indiquer un événement : un but (il faut pouvoir dire qui a marqué et qui a fait la passe décisive (facultatif), un but encaissé, un changement de poste, il faut qu’aux temps définis au préalable par les compos créés par le coach, l’application propose au coach d’appliquer la nouvelle compo : les changements sont effectués lorsque le coach valide. Il faut aussi la possibilité de indiquer un changement simple. Pour les changements (hors compo prédéfinie), il faudrait faire un mode « terrain » ou l’on peut drag and drop les joueurs à des postes, le banc compris. Une fois la compo choisie, on confirme. Cela permet de faire plus rapidement les changements. Ce mode peut aussi être disponible au coach lorsqu’il crée la composition de base. 
- Il faut en gros une fonctionnalité ou à chaque fois on peut rentrer une action comme sur Waze ou on dit que quelque chose se passe soit un changement soit un but soit un but encaissé, une passe d, une faute une blessure avec un chrono pour le match
- Statistiques générales de l’équipe : par joueur, nombre de but, passes décisives, matches joués,minutes d’invincibilité. Tout ce qu’il se passe sur le terrain doit être enregistré en base. 
- Possibilité aussi de marquer des joueurs comme supporters : si tu viens à un match, tu es soit goal, joueur de champ, remplaçant ou supporter. Tu peux aussi être titulaire ou remplaçant (au début du match). Dans les stats générales il faut indiquer combien de fois tu es venu en joueur, en supporter, etc. 
- Les joueurs doivent pouvoir être marqués comme blessés: ils l’indiquent eux même, ou le coach peut le faire. 
- Pour un match spécifique, il faut que les joueurs puissent indiquer s’ils seront présents ou non. Le coach peut indiquer qui est sélectionné pour le match, faire une compo, et prévoir des changements à l’avance. Les changements peuvent être poste par poste ou bien avec des changements de poste (ex l’attaquant passe milieu, le remplaçant passe attaquant, le milieu passe goal et le goal sort)
- L’application doit être pensée pour mobile, à utiliser dans le navigateur. Il faut aussi qu’elle soit utilisable sur l’ordinateur. 
- Elle sera déployée sur vercel, et il faut de la rétention de données. 
- Il faut aussi intégrer la gestion des entraînements : les calendrier d’entraînement, dire si on est présent ou pas, qui a été présent ou non
